# Customer Churn Analysis

## Objective
The objective of this project is to analyze customer churn and identify the factors associated with customer retention and churn.

## Dataset
The dataset contains customer information such as:
- Gender
- Senior Citizen
- Partner
- Dependents
- Tenure
- Internet Service
- Contract
- Payment Method
- Monthly Charges
- Total Charges
- Churn

## Tools Used
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Power BI
- Power Query
- DAX

## Analysis
The project analyzes:
- Overall customer churn
- Churn by contract
- Churn by internet service
- Churn by payment method
- Churn by gender
- Churn by tenure
- Monthly charges
- Total charges
- Customer segments

## Python Visualizations
The project includes:
- Churn distribution
- Contract analysis
- Internet service analysis
- Payment method analysis
- Tenure analysis
- Monthly charges analysis
- Tenure vs monthly charges
- Correlation heatmap

## Power BI Dashboard
The dashboard includes:
- Total Customers
- Churned Customers
- Retained Customers
- Churn Rate %
- Average Monthly Charges
- Average Tenure
- Churn by Contract
- Churn by Internet Service
- Churn by Payment Method

## Key Insights
- Overall churn rate is approximately 40.55%.
- Month-to-month customers show higher churn.
- Electronic check customers show higher churn.
- Fiber optic customers show higher churn.
- Short-tenure customers show higher churn.
- Higher monthly charges are associated with churn in this dataset.
